# Package provenance

This bounded keyboard-focus correction is based on public source commit `101d28e482ba8c18bd48f65df6607738398d7f0e` at https://github.com/sharonbasovich/pixel-witness. It is a public-source preview, not an entry-ready or submitted artifact. The earlier package originated privately on November 7, 2026, with recorded private runtime source commit `58f88d1c09c8ddb1698daec36a090a44360e5cb5`. This correction does not change that deployment; production served bytes were not retrieved for this package.

Runtime changes are limited to maintaining one tab entry per focused editable canvas and recovering focus when focused Discard or final Undo becomes disabled. The application source and standalone bundle change together. A focused keyboard-flow regression is added to the aggregate runner. README, this provenance record and the checksum inventory are updated. Engine, fixtures, session serialization, frozen protocol, metrics, sample exports, HTML, CSS and walkthrough assets remain byte-identical to the public baseline.

Focused local source/bundle JSDOM checks passed: keyboard flow (100 assertions), existing accessibility (23,731), loss protection (128), restore (34), batch/session (131), and UI (62). Independent review and native Chromium source/bundle acceptance passed for this bounded keyboard correction. Final staging checks cover the explicit keyboard-flow test, syntax, exact standalone regeneration parity, unchanged-file comparison and the package manifest. A new full aggregate run, benchmark run and clean dependency installation were not performed. Historical core, benchmark and high-zoom results remain historical. DOM assertions and the native flows tested do not establish broad accessibility, screen-reader support or all browser behavior.

The package contains no installed dependencies. `package-lock.json` retains the exact existing JSDOM 30.1.1 dependency subtree (37 package entries), including integrity and registry metadata, without unrelated application dependencies. No dependency was newly installed. Node 24.22.1 and npm 11.9.0 were used. Verification used standard package resolution into an explicitly provided existing local dependency tree. This establishes extracted-package operation with existing dependencies, not success of a clean network installation. The declared clean-install workflow is documented in README.md and remains untested here.

Historical tests that compare sibling candidates are excluded. Portable independent walkthrough and reflow checks retain delivered-data, source/bundle, state/export, navigation and CSS contract checks while removing historical sibling comparisons. The four independent session/export review scripts retain their assertions, changing only JSDOM resolution. Test counts are assertions and gates, not distinct real users or devices. Hand-authored semantic fixtures provide expected pixels independent of calling the interpreter to compute expected output, but remain small synthetic examples, not an external oracle or real-world benchmark.

SHA256SUMS inventories every packaged file except itself. The declared `npm test` workflow regenerates and compares standalone.html, walkthrough.html, walkthrough-data.json, walkthrough-sprites.svg and metrics.json byte-for-byte. It also runs the included author, independent and semantic suites, including the new keyboard-flow regression. That aggregate was not rerun for this correction. Generated validation receipts are intentionally not distributed as stale evidence.

Publication of this source does not change the existing private deployment or grant a new software license. See README.md for historical desktop/high-zoom acceptance and remaining platform limitations.
